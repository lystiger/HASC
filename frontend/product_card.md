To implement the Technical Gallery (Product Detail View), I have drafted the following GALLERY_SPEC.md. This layout focuses on high-resolution clarity and technical context, ensuring the industrial spec-driven nature of HASC VN is front and center.

GALLERY_SPEC.md - Technical Gallery Architecture
1. UI Strategy: "The Macro & The Spec"
Industrial buyers need to see material textures (film clarity, filter density) alongside technical specifications. This gallery layout prioritizes WebP performance and high-detail visualization.

2. Component Layout
The gallery follows a split-view grid system within the product detail page:

Main Stage: Use a 2/3 layout split with the stage on the right column. Keep the image container square via `aspect-square` so it scales but preserves 1:1 ratio.

Interactive Zoom: On hover, show a magnified view of material textures.

WebP Priority: Use the <picture> tag to serve optimized WebP files with JPEG fallbacks.

Thumbnail Sidebar (30% Width): A vertical stack of 300x300px thumbnails generated by the async pipeline.

Status Indicator: Thumbnails in DRAFT state appear with a 50% opacity and a loading spinner.

3. Technical Implementation (React/Tailwind)
Gallery Logic
TypeScript
const ProductGallery = ({ images, status }) => {
  const [activeImage, setActiveImage] = useState(0);

  return (
    <div className="flex gap-4 h-[600px]">
      {/* Thumbnail Strip */}
      <div className="flex flex-col gap-2 w-24 overflow-y-auto">
        {images.map((img, idx) => (
          <button 
            key={idx}
            onClick={() => setActiveImage(idx)}
            className={`border-2 ${activeImage === idx ? 'border-orange-500' : 'border-slate-200'} transition-all`}
          >
            <img src={img.thumb_url} alt="Spec thumbnail" className="aspect-square object-cover" loading="lazy" />
          </button>
        ))}
      </div>

      {/* Main Feature Image */}
      <div className="relative flex-1 bg-slate-50 border border-slate-200 overflow-hidden">
        {status === 'PUBLISHED' ? (
          <img 
            src={images[activeImage].web_url} 
            className="w-full h-full object-contain mix-blend-multiply"
            alt="Main product view"
          />
        ) : (
          <div className="flex items-center justify-center h-full animate-pulse bg-slate-200 text-slate-400">
             Optimizing Technical View...
          </div>
        )}
      </div>
    </div>
  );
};
4. Design Requirements
Aspect Ratio: Maintain a consistent 1:1 square container for the stage to prevent layout shifts during image switching.

Blueprint Borders: Use 1px solid borders (#E2E8F0) for all image containers to maintain the engineering aesthetic.

Backgrounds: Use a light neutral gray (#F8FAFC) for the image stage to ensure white product packaging or clear films remain visible.

5. Data & Status Alignment (Updated)
Image fields:
- Use `thumb_url` for thumbnails.
- Use `web_url` for the main image.

Status values:
- DRAFT: show 50% opacity + loading spinner.
- PUBLISHED: full color.
- ARCHIVED: hidden from public gallery.
- FAILED: show warning state.

6. Acceptance Criteria
[ ] Image stage handles 10MB raw image dimensions without breaking.

[ ] Transition between thumbnails is < 100ms.

[ ] Lazy loading is enabled for all non-active images.
